# Changelogs

One file per conversion. The first line is the output file name
(`COURSE-TERMCODE-Topic.html`) and is the only place the course code and term
code appear. The body is a record, not an explanation: every image or graph
passage (converted, grouped into which widget, or skipped and why), every prose
edit, any conflict between sources, every value carried over in
change-by-message mode, and every example that still needs numbers.

The changelog for the Fall '26 Supply and Demand build
(`transcript-test-changelog.md`) was part of `eco-widgets.zip` and has not
reached the repository. See `docs/open-issues.md`.
