# Reference images

The thirty PNGs the ECO2013 Supply and Demand notes use
(`eco2013-spring26-supplydemand-NN-*.png`) belong here. They are in
`eco-widgets.zip`, which never reached this repository — see
`docs/open-issues.md`.

They are the printed artwork the widgets have to match, so they are worth
restoring before the next conversion: rule 5 is "match the printed artwork", and
without them that is a judgement call from memory.
