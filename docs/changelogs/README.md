# Changelogs

One file per conversion. The first line is the output file name
(`COURSE-TERMCODE-Topic.html`), and the body is written to be scanned: one line
per widget, every value carried over rather than taken from the source,
everything flagged *needs numbers*, anything that stayed close to source wording,
and what was grouped into scenarios.

`transcript-test-changelog.md` — the changelog of the first real run (the Fall
'26 Supply and Demand build, nine widgets, transcript only) — is in
`eco-widgets.zip` and never reached this repository. See `docs/open-issues.md`.
